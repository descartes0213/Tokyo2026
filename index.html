淺草寺與雷門大紅燈籠

東京都內最古老的寺廟，創建於西元 628 年。象徵性的紅色巨型燈籠上書寫著「雷門」二字，是世界級的地標。

私房小故事：燈籠底部的木雕龍

多數旅客僅在正面拍照，但走進燈籠正下方抬頭，會發現底座雕刻著一條栩栩如生的木雕龍！淺草寺的正式山號為「金龍山」，木雕龍除了展現江戶工藝，更是祈求水神守護下町、免受火災之災的象徵。

CC0 Public Domain

明治神宮與永恆之森

為供奉明治天皇與昭憲皇太后而建。神宮四周廣達 70 公頃的茂密森林看似天然，實為百年前動員全國以林學規劃出的人工「永恆之森」。

私房小故事：來自台灣的千年檜木鳥居

位於南北參道交會處的巨型木造大鳥居（日本最大木造明神鳥居），原建材遭雷擊受損後，特地自台灣海拔三千公尺的丹大山與阿里山引進樹齡逾千年的特選紅檜巨木重建，成為台日歷史的深厚見證。

CC0 Public Domain

東京麵包祭與職人烘焙文化

東京是全球烘焙密度最高的城市之一，每年定期舉辦的「麵包祭（パンのフェス）」總吸引數萬麵包迷朝聖。

私房小故事：只專注做兩種麵包的 Pelican

淺草創立於 1942 年的「Pelican（白鵜鶘）」，創始店八十年來只販售吐司與餐包，不加人工香精，純靠單純的麵粉香與天然筋度征服老東京人。烘焙職人堅持清晨以炭火出爐，是品味東京慢活早餐的最佳代表。

CC0 Public Domain

河口湖與秋日逆富士

富士五湖中景致最富變化的湖泊。秋風澄淨時分，湖面如鏡，倒映著雄偉的富士山，名為「逆富士」。

私房小故事：日幣紙鈔背後的倒影

千圓日幣紙鈔背面所印製的「湖畔之富士」，靈感正是取自這片水域。清晨風平浪靜的片刻，大自然在此呈現出最完美的對稱美學。

CC0 Public Domain

聖山富士山 (標高 3,776m)

日本最高峰，自古被尊為神靈棲息的聖地。2013 年被登錄為世界文化遺產，代表著「信仰的對象與藝術的泉源」。

私房小故事：不死的竹取物語傳說

日本古老文學《竹取物語》結尾中，輝夜姬返回月球前贈送天皇不死之藥，天皇命人在最接近上天的火山口將藥焚毀，「不死」的日文發音（Fushi）與長年上升的白煙，便演變成了富士山（Fuji）的名字由來。

CC0 Public Domain

新倉山淺間公園與忠靈塔

登上 398 階階梯後抵達的觀景平台，將紅色五重塔與富士山一同框入眼簾，曾登上米其林旅遊指南封面。

私房小故事：咲くや姫階梯與平和祈願

這座紅色五重塔建於 1962 年，原為追悼戰歿軍民而建的紀念塔（忠靈塔）。通往山頂的 398 階階梯被命名為「咲くや姫階段」，源於富士山主祭女神木花咲耶姬，象徵著守護家園與祈願和平的誓約。
